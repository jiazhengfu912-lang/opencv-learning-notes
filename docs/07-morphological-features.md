# 07 形态学特征：梯度、礼帽与黑帽

[上一章：形态学基础](06-morphology-basics.md) · [教材目录](README.md) · [下一章：图像梯度算子](08-image-gradients.md)

## 学习目标与前置知识

- 理解形态学梯度、礼帽和黑帽的来源。
- 知道它们分别突出边缘、小亮细节和小暗细节。
- 会根据目标尺度选择不同大小的结构元素。

前置知识：腐蚀、膨胀、开运算、闭运算及结构元素。

## 核心理论

这三个操作都由前一章的基本形态学运算组合而来：

| 名称 | 公式 | 突出内容 |
| --- | --- | --- |
| 形态学梯度 | $dilation(src) - erosion(src)$ | 物体轮廓和边缘 |
| 礼帽（Top Hat） | $src - opening(src)$ | 比结构元素小的亮区域 |
| 黑帽（Black Hat） | $closing(src) - src$ | 比结构元素小的暗区域 |

```text
原图：       开运算：      礼帽结果：
  背景+亮点    背景平滑       小亮点

原图：       闭运算：      黑帽结果：
  背景+暗点    背景填平       小暗点
```

结构元素大小决定“多大算小细节”。若目标亮斑比核小，开运算更容易去除它，礼帽就会把它提取出来；核太小则目标可能被保留，提取效果变弱。

## 对应实践

对应脚本：[形态学特征示例](../morphology_features.py)

```powershell
python morphology_features.py
```

脚本将 `images/test.jpg` 转成灰度图，创建两个椭圆结构元素：`5 × 5` 的 `edge_kernel` 用于形态学梯度，`15 × 15` 的 `hat_kernel` 用于礼帽与黑帽。输出显示原灰度图、梯度、礼帽和黑帽结果，并保存到 `output/`。

## 参数速查与常见误区

| 写法 | 作用 |
| --- | --- |
| `cv2.morphologyEx(src, op, kernel)` | 执行扩展形态学操作 |
| `cv2.MORPH_GRADIENT` | 膨胀减腐蚀，突出边缘 |
| `cv2.MORPH_TOPHAT` | 原图减开运算，提取小亮细节 |
| `cv2.MORPH_BLACKHAT` | 闭运算减原图，提取小暗细节 |
| `(5, 5)` / `(15, 15)` | 结构元素宽高，通常取奇数 |

常见误区：

- 把形态学梯度与 Sobel 梯度当成同一种计算；两者都能显示边缘，但数学基础不同。
- 认为礼帽只和“白色”有关；它提取的是相对周围更亮的小结构。
- 不根据目标尺寸调整核大小，导致细节提取不到或背景被带入结果。

## 复习卡

关键结论：梯度提边缘，礼帽提小亮细节，黑帽提小暗细节；核大小决定被强调的尺度。

<details>
<summary>自测 1：形态学梯度为什么会突出边缘？</summary>

物体内部的膨胀和腐蚀结果较接近，而边缘附近差异明显；两者相减后边缘被保留。
</details>

<details>
<summary>自测 2：想找亮背景中的细小暗划痕，应优先观察哪一种结果？</summary>

黑帽结果，因为它突出相对背景较暗、且尺度较小的结构。
</details>

<details>
<summary>自测 3：礼帽的结构元素变大，通常会改变什么？</summary>

会改变“背景”和“小亮细节”的尺度划分；更大的核可忽略更大范围的平滑背景，但也可能带来更多背景变化。
</details>
